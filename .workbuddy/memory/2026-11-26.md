
## husky → vite-plus 钩子迁移（49c7859，2026-11-26）

- pre-commit（typecheck+lint）从 .husky/ 迁至 .vite-hooks/，vp config --hooks 安装分发器（core.hooksPath=.vite-hooks/_，_ 已 gitignore）。
- 坑：①vp config 不带参数且 stdin 开着会挂死（等交互），必须 `</dev/null` + 显式 `--hooks --no-agent`；②vp 检测到 core.hooksPath 已被占用会跳过安装，迁移前必须先 `git config --unset core.hooksPath` + 卸 husky；③vite-plus npm 包依赖自带 vite/vitest/oxlint 全家桶（会与项目现有工具链冗余），故不加 devDep，prepare 用 `command -v vp &&` 守卫（CI/无 vp 环境跳过不阻断 install）。
- 本沙箱内 husky/vp 长命令（>120s 前台）会被 SIGTERM 杀（exit 137），一律 run_in_background。
