### 可复用的验收手法（写进日常巡检）
- 查构建：`cnb build get-build-logs --repo jackytse/wocnb --createTime YYYY-MM-DD --page-size N`
  （含 pipelineTotalCount/pipelineSuccessCount 与每 pid 状态）
- 查 Release + 附件：`GET https://api.cnb.cool/{repo}/-/releases?page=1&page_size=3`，
  token 在 `~/.cnb/token`（**JSON 结构 `auths['cnb.cool'].access_token`，不是裸 token 串**，直接 cat 会 curl 43）
- 附件下载域名同为 api.cnb.cool 的 `/releases/download/{tag}/{file}`，带同一 Bearer 可直下
- 构建日志页 `/-/build/logs/{sn}` 是 JS 渲染，WebFetch 取不到内容，别指望抓日志文本
