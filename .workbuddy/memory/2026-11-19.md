## 标签（label）配色修复 + rc.34 发版（提交 f438901 / e9c171d，tag v0.1.0-rc.34）

- **现象**：首页「我创建的」列表里，Issue 标签渲染成一块近乎空白的浅色方块，字看不见（用户截图反馈"标签颜色很奇怪"）。
- **根因（实测 API 确认）**：CNB `GET /user/issues` 返回的 `label.color` 是 **#E5F5FF、#FCEEE8 这类极浅粉彩**（H 高饱和 + L≈95%）。旧实现两种写法都错：
  - 首页 `HomeIssueList.vue`：`variant="subtle"` + `color: label.color` → 近白字压近白底；
  - 仓库页（IssueList / IssueDetail / PullList）：`color: label.color` + `backgroundColor: ${color}1a` → 白底上叠 10% 同色 ≈ #FBFDFF，同样看不见。
  - PR 详情是「中性徽标 + 色圆点」，圆点同样接近白色，看不出颜色。
- **修复**：
  - 新增 `src/utils/labelColor.ts`：`normalizeLabelColor`（3/4/6/8 位十六进制、去 #、非法返回 null）、`relativeLuminance` / `contrastRatio`（WCAG，注意必须做 gamma 反变换）、`readableTextColor`、`labelChipStyle`。
  - 前景色策略：浅底（相对亮度 ≥0.5）→ **同色相压暗 + 饱和度×2.2**，从 L=0.38 每档降 0.04 取第一个 ≥4.5:1 的候选（#E5F5FF → #006bad、#FCEEE8 → #c23a00，保留色相关联）；中深色底 → 白 / #111827 / #000 依序取第一个达标者（#ff0000 只有纯黑能过 5.25:1；#111827 是 4.44、白是 3.96）。
  - 底色用**标签色本身（不透明）**，因此明暗主题下表现一致，不需要主题分支；配 `inset 0 0 0 1px rgba(0,0,0,.08)` 内描边（用 border 会改变盒高，同行徽标会高低不齐）。
  - 新增 `components/LabelChip.vue` 作为标签唯一出口（无可用颜色时回落中性徽标），5 处调用点全部收敛（首页 / 仓库 Issue 列表 / Issue 详情 / PR 列表 / PR 详情）。
- **测试**：新增 `src/utils/__tests__/labelColor.test.ts` 13 例，把「对比度 ≥ 4.5:1」写成断言（真实色值 #E5F5FF、#FCEEE8 做了回归）；全量 44 文件 **704** 用例全绿，typecheck / lint / build 通过。
- **发版**：rc.34，ci-main `cnb-71t-1k7ol4nil` 全绿；tag 构建 `cnb-lm4-1k7ol76qn` 三条流水线全绿（meta 57s / macos 72s / windows 96s，rust toolchain 缓存已热，不再全量重编），Release 7 个附件齐全、prerelease=true。
- **观察项（未改，待用户决定）**：所有页面的 UTabs 都是 `color="neutral"` + pill，Nuxt UI v4 的 neutral 选中态是 `bg-inverted` → 浅色主题下是一块纯黑药丸（截图里"我创建的"就是），与整体浅色 UI 反差很大。若要改需要统一覆盖 tabs 主题或加一层 AppTabs 包装，属全局视觉变更，没在这次一并动。

## 应用内热更新（macOS，tauri-plugin-updater）落地（提交 801e054）

- **决策（用户拍板）**：macOS 先行（Windows 节点 makensis 起不来，rc 只出裸 exe，更新器必须依赖 NSIS/MSI 安装器产物 → 无法自更新）；签名私钥走 **CNB 密钥仓库**（用户需亲自创建仓库，token 缺 group-resource:rw 不能代建）。

## 滚动条终局方案 + 探索弹窗 + 窗口尺寸（提交 85085a1，2026-11-19 上午三批）
