## 托盘面板滚动条修复（7e99ca7）

- 现象：面板列表超长时无滚动条。**根因是 CSS 层叠层级**：main.css 顶部 `* { scrollbar-width: none }` / `*::-webkit-scrollbar{display:none}` 是未分层（unlayered）规则，Tailwind 工具类在 @layer utilities 里 —— 未分层规则恒优先于任何 @layer 规则（与选择器优先级无关），所以 `[&::-webkit-scrollbar]:block`、`[scrollbar-width:auto]` 等任意变体全部失效。实测：计算值恒 none、scrollbar 占位 0px。
- 修复：main.css 追加未分层规则 + `[data-tray-scroll]` 属性选择器（scrollbar-width:auto + ::-webkit-scrollbar 8px + 透明边框 + background-clip:content-box 做 4px 悬浮滑块，深浅两套）；TrayPanel 滚动容器改用 `data-tray-scroll` 属性。
- **重要经验（通用）**：在 Tailwind v4 项目里要覆盖 main.css 这类未分层全局规则，必须同样写在未分层位置（或内联 style），Tailwind 任意变体一律打不过；验证手法用 headless Chrome iframe + `offsetWidth-clientWidth`（经典滚动条占 8px），别只看截图（headless 可能不画滚动条）。
- 另：托盘面板 localStorage 种子数据 time 必须是 ISO 字符串（useRecentRepos 校验），数字时间戳会被整体过滤成空列表。
